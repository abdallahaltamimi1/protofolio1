# protofolio1
👨‍💻 Personal Portfolio — Abdullah Altamimi

A responsive personal portfolio website created to showcase my background, education, skills, projects, references, and journey into web development.

The portfolio represents the connection between my background in Physics and my growing passion for Programming and Technology, with a focus on problem-solving, creativity, continuous learning, and building practical solutions.

🎯 Project Overview

This project is a personal website designed to provide a professional online presence and introduce visitors to my background and development journey.

The website includes several sections that present information about me, my qualifications, technical and soft skills, projects, references, and contact information.

The design focuses on keeping the interface simple, clean, modern, and responsive while using a consistent color palette throughout the website.
